1) Revisión — Propósito y cómo

Propósito:
Comprobar el estado actual del repositorio, la estructura y los artefactos esenciales para garantizar reproducibilidad y trazabilidad.

Pasos sencillos:
1. Listar archivos principales: `README.md`, `package.json`, `prisma/schema.prisma`, `.github/workflows`.
2. Verificar que `src/` y `src/modules/` existen y tienen README de módulo.
3. Confirmar `.gitignore` y ausencia de secretos en commits.
4. Registrar hallazgos en un archivo `docs/review-YYYYMMDD.txt`.

Lista de verificación mínima:
- [ ] `README.md` presente
- [ ] `package.json` o equivalente presente
- [ ] `prisma/schema.prisma` (si aplica)
- [ ] `.gitignore` cubre secretos
